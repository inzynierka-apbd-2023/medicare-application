## 🚀 Quick Start

1. **First-time setup:**
   ```bash
   npm install
   ./setup-hooks.sh
   ```

2. **Development:**
   ```bash
   npm run dev
   ```

3. **Building:**
   ```bash
   npm run build
   ```
